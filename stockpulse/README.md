# StockPulse AI

GitHub Pages 靜態台股研究工具，入口為 `/stockpulse/`。瀏覽器直接查詢官方公開來源，不需要 API 金鑰、第三方代理、開發伺服器或 OpenAI API。自選股保存在當前瀏覽器；行情與匯入檔只保留於目前頁面工作階段。

## 行情與更新

- 上市盤後使用 [證交所每日收盤行情](https://www.twse.com.tw/zh/trading/historical/mi-index.html) 的指定交易日報表，上櫃盤後使用 [櫃買中心股票收盤行情](https://data.gov.tw/dataset/11371) 的最近清單。可匯入 [證交所個股日成交資訊](https://data.gov.tw/dataset/11549) 或櫃買中心的開放資料 CSV。盤後報價按市場個別顯示實際交易日與取得時間。
- 個股日 K 使用 [證交所歷史查詢](https://www.twse.com.tw/zh/trading/historical/stock-day.html) 或 [櫃買中心歷史查詢](https://www.tpex.org.tw/zh-tw/mainboard/trading/info/stock-pricing.html) 的官方月報。若官方來源阻擋跨站讀取、暫時離線或限制頻率，從同一官方查詢頁下載 CSV，再選取同一個股的月份檔案批次匯入。篩選器另支援政府資料集的盤後清單 CSV。
- 官方日 K 和盤後清單都沒有即時串流。盤後清單可能仍是上一交易日，節假日也以資料本身日期為準。使用者匯入的分鐘資料始終標示「歷史快照」。
- 匯入你有權使用的分鐘 CSV 可啟用原生 1／3／5／15 分 K。具足夠連續 1 分 K 時也可聚合完整的 3／5／15 分區間，缺棒略過。分鐘 `time` 使用台北時間的 K 棒開始時間，格式 `YYYY-MM-DD HH:mm`，非全天時間可匯入但 VWAP 只會在從 09:00 開始且連續的資料上顯示。成交金額 `amount` 須與股數同口徑。可接受官方中文欄位或 `date,time,code,open,high,low,close,volume,amount` 中適用欄位。

## 指標與回測

- MACD 使用 EMA 12／26，訊號線 EMA 9，柱狀圖為 DIF 減訊號線。KD 使用 9 期 RSV、K/D 自 50 起算。RSI 使用 Wilder 14 期平滑。VWAP 使用同日累計成交金額除以累計成交股數，缺成交金額或期間缺棒時顯示空白。
- 量價篩選依成交股數與漲跌幅排序。相對量預設停用，啟用後要求同口徑最新日 K 與先前 20 根 K 棒，缺資料的股票不計入命中。盤後漲跌幅從官方漲跌價差及其隱含的參考價計算；個股序列的變動率使用相鄰收盤價。
- 單股回測於日 K 收盤觸發、下一根開盤成交、持有指定根數後開盤出場，按單邊成本估計淨報酬；單一持倉、僅統計完整交易。價格未還原，除權息或分割會影響結果。回測假設開盤可按報價成交，未重現撮合或漲跌停無法成交情形。
- 快照附來源、週期、資料時間、取得時間與最近 30 根 K 棒，可複製或下載 JSON，供 ChatGPT 分析。
